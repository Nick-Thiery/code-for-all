Your site only knows its own files. An API is how it borrows data from someone else.

<KeyTerm term="API">
Something that lets your site borrow data from someone else. You send it a request for information, and it answers with data.
</KeyTerm>

## Think of it like a door

Think of an API like a door. You knock with a request for information, it answers with data. You never see the inside, and you don't have to.

<ApiDoorDiagram />

## Where the API sits

- **End user:** you, on a browser or mobile.
- **App:** the interface.
- **API:** the messenger.
- **Server + DB:** where data lives. (DB is short for database.)

The API is the messenger: it takes the app's request to where the data lives, and brings the response back. A server is a computer somewhere else that answers requests. A database is where it keeps its data.
