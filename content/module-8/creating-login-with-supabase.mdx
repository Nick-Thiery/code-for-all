Your turn! You've seen [how logging in works](/module-8/how-logging-in-works). Now add it to your own page.

Supabase is a service that gives your site a database and <Term>authentication</Term>, so it can remember users. Its free plan is all you need.

The three actions you're adding are the ones from [lesson 4](/module-8/how-logging-in-works):

## 1. Sign up for Supabase

This part needs access; see [how hands-on access works](/access). You sign in to Supabase with a GitHub account, so do this step in a session, with your teacher's go-ahead.

Take 60 seconds:

1. Go to [supabase.com](https://supabase.com) → click **Start your project** → **Continue with GitHub**.
2. Set up a database password and save it (this is **NOT** your login password).
3. Pick the recommended region.

## 2. Get your two values

In your Supabase project:

1. Go to **Project Settings**.
2. Go to **API Keys**.
3. Copy **Publishable Key**.
4. Go to **General**.
5. Copy **Project ID**.
6. Go to **Authentication**.
7. Disable **Confirm Email**.
8. Click **Save changes**.

Keep the Publishable key and the Project ID somewhere handy. They go into the prompt in the next step. A key is a long code that proves to Supabase which project is asking.

<Callout kind="headsup">
Turning off **Confirm Email** is fine for practice, but don't do it for a real app. And when you try out your sign-up, use a test email, not your own.
</Callout>

## 3. Paste this into Claude

"This page" in the prompt means the page of the project you used in [Task 1](/module-8/put-live-data-on-your-page).

```prompt title="Paste this into Claude"
Add email signup, login and logout to this page using Supabase.

Load supabase-js from
https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2

Project URL: https://<your project id>.supabase.co
Publishable key: <paste yours>

When someone is logged in, show their email and a log out button.
```

Before you send it, swap `<your project id>` for the Project ID you copied in step 5, and `<paste yours>` for the Publishable key from step 3.

This will add:

1. One **script tag** that loads Supabase.
2. One line that connects using your two values.
3. Three buttons: sign up, log in, log out.
