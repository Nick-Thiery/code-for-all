Time to fix the second thing your site can't do. You'll use the weather API from [lesson 2](/module-8/what-an-api-is) to put live data on your page.

<HandsOn />

## 1. Open any project

This part needs access; see [how hands-on access works](/access).

You can quickly fork the Wordle project you built in [Module 7](/module-7/recreate-wordle) and use the copy to do this.

## 2. Paste the prompt into Claude

```prompt title="Paste this into Claude"
When my page loads, fetch this URL:

https://api.open-meteo.com/v1/forecast?latitude=1.29&longitude=103.85&current=temperature_2m

and show the current temperature in a small box at the top of the page.
```

This will update your site with the live temperature of Singapore.

<Callout kind="tip">
Remember to link the chat to the correct repo and push the changes. Also make sure that new repo is connected to Vercel so that you can see changes. [Module 6](/module-6/connect-to-vercel) shows how to connect it.
</Callout>

## 3. Check it worked

Refresh the page. A real temperature, from a real weather service, that changes every time you reload.
