Your project is on GitHub. Now connect it to Vercel, which turns it into a live website.

<HandsOn />

## 1. Sign in with GitHub

Go to [vercel.com](https://vercel.com) and sign up using your **GitHub account**, not email. This is what lets Vercel see your repos.

This part needs access; see [how hands-on access works](/access).

## 2. Import your repo

On your dashboard, click **New Project** → **Import Git Repository** → pick the repo you pushed in [Step 1](/module-6/get-your-code-into-github). Authorize Vercel when GitHub asks.

## 3. Deploy

Vercel auto-detects your setup. Click **Deploy**, wait a few seconds, and you get a **live public link**.

<Callout kind="tip">
**From now on, you never upload anything again.** Every time you push to GitHub, Vercel rebuilds and updates your live site automatically. And every pull request gets its own preview link, so your team can see changes before merging.
</Callout>

That's the task done: your latest project is on GitHub, and it's live on Vercel.

2. Fork it and send it to Vercel. Your fork is a repo on your GitHub account, so you import it just like you did in step 2 above.
3. Also review the new terms from this module: fork, clone, commit, push, pull request and merge. [Key terms](/module-6/key-terms) has them all. VERY IMPORTANT!
