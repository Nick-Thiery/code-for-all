Push and pull request are two ways to add your changes to a project. The difference is whether anyone checks them first.

## Push

- **Direct action:** Uploads your commits straight to the repo: no waiting, no approval.
- **No review:** Changes go live immediately on whatever <Term def="your own parallel copy of the code, inside the same repo. You'll learn about branches in Module 7.">branch</Term> you push to.
- **Use when:** Working solo or on your own branch and you're confident in your changes.

## Pull request

- **Request for review:** Propose your changes and ask teammates to look before anything is merged.
- **Discussion:** Others can comment, suggest edits, and approve or reject the changes.
- **Use when:** Working on a team or contributing to someone else's project.

In this module you work on your own project by yourself, so you'll push. You'll open pull requests in [Module 7](/module-7).
