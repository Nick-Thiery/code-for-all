So far you've built projects with Lovable and Claude Code. This module is about where that code goes next: GitHub to keep it, and Vercel to turn it into a live website.

GitHub is your project's online home.

## Store, share, collaborate

1. **Store.** Keep all your project files and their history in one location. This place is called the repository.
2. **Share.** Easily make your work accessible. You can make it public so that anyone can see, use, and learn from what you have done.
3. **Collaborate.** Work with your friends or coworkers without overwriting each other's <Term def="all the code in a project.">codebase</Term>.

<KeyTerm term="Repository">
The one location where all your project files and their history are kept. On GitHub, it's your project's online home. People call it a **repo** for short.
</KeyTerm>

A project's history means every version of every file, not only the latest one.

## How it works

Your computer and GitHub each keep a copy of your project.
