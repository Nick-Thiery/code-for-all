GitHub stores your code. Vercel is what turns it into a live website.

This is similar to tiiny.host! In [Module 5](/module-5) you could launch your website on tiiny.host by zipping your files and uploading them. Vercel reads your files straight from your GitHub repo instead.

## Connect, deploy, preview

1. **Connect.** Link your GitHub repo to Vercel once. From then on, Vercel watches that repo for you.
2. **Deploy.** Every time you push, Vercel grabs the new code and updates your live site in seconds: no manual uploading, ever.
3. **Preview.** Every pull request gets its own preview link, so your team can see the changes before merging them.

## What's the difference between GitHub and Vercel?

GitHub stores your code: every file, every version, shared with your team. But nothing there is a website yet.

Vercel turns that code into one. It reads your repo, builds the site, and hosts it at a public link that updates every time you push.
