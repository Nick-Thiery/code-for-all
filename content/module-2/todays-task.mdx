In Module 1 you learned how to write a strong <Term>prompt</Term>. In this module you'll use that skill on a real project.

## Today's task

There are three different sites to choose from. Pick the one you want to build:

- **Personality quiz**
- **News website**
- **Online store**

Pick the one you'd enjoy most. There's no wrong choice.

## What each site is

Here's what each one usually has, to help you choose. These are ideas, not rules: your prompt decides what goes in.

### Personality quiz

A site that asks visitors a few questions, then tells them which "type" they are. Think "Which noodle are you?" or "What kind of learner are you?".

- A start page with a big button to begin.
- The questions, each with a few answers to pick from.
- A results page that says which type you are, and why.

Pick this if you like fun, silly ideas and want something people can play.

### News website

A site full of short articles about one topic, like school sport, science or games.

- A home page with the latest stories.
- A page for each story, with a headline and the article.
- Sections for different topics, so readers can find what they like.

Pick this if you like writing, or you have a topic you could talk about all day.

### Online store

A site that shows things for sale, like a shop window on the internet.

- A home page that shows off the shop.
- A page with all the products, each with a picture, a name and a price.
- A page for each product, and a basket.

Pick this if you like design, or you've ever dreamed up your own brand. Make the shop and its products up. Your store is for practice, so leave out real payments.

## What happens next

You'll work on the site you picked for the rest of this module:

1. Build a first draft in Lovable. ([Solo sprint](/module-2/solo-sprint))
2. Ask Claude to help you make your prompt better. ([Using AI to make better prompts](/module-2/better-prompts-with-ai))
3. Give the better prompt to Lovable. ([Using refined prompts](/module-2/using-refined-prompts))
4. Compare your two versions. ([Gallery](/module-2/gallery))

<PromptLoopDiagram />

It's a bit like writing an essay. You write a first draft, a friend reads it and suggests what to make clearer, then you write it again. The second version is better because you know more about what you want. Here, Lovable builds your draft and Claude is the friend who helps with your prompt.

Lovable and Claude both run in your browser. You use them through your Code for All access, so there's nothing to install and nothing to pay.

## An example

Say you pick the personality quiz. Here's how the module goes for you:

1. In the solo sprint, you write a prompt for a quiz called "Which noodle are you?", with five questions and six results. Lovable builds it.
2. The results page looks plain, and Lovable picked colours you didn't ask for. You ask Claude to help make your prompt clearer about the look.
3. Claude's version names the colours, the fonts and what goes on each page. You give it to Lovable.
4. You put the two versions side by side and spot three things that changed.
