In Module 1 you learned how to write a strong prompt. In this module you'll use that skill on a real project.

## Today's task

There are three different sites to choose from. Pick the one you want to build:

- **Personality quiz**
- **News website**
- **Online store**

## What happens next

You'll work on the site you picked for the rest of this module:

1. Build a first draft in Lovable. ([Solo sprint](/module-2/solo-sprint))
2. Ask Claude to help you make your prompt better. ([Using AI to make better prompts](/module-2/better-prompts-with-ai))
3. Give the better prompt to Lovable. ([Using refined prompts](/module-2/using-refined-prompts))
4. Compare your two versions. ([Gallery](/module-2/gallery))
