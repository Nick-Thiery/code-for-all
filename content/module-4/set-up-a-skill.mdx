Here's how to add a skill of your own to Claude, so it can use your instructions whenever they fit.

<HandsOn />

## Four steps

This part needs access; see [how hands-on access works](/access). Open Claude using the access your Code for All session gives you.

1. **Access Portal.** On Claude.ai, go to **Customize**, then **Skills**.
2. **Add Skill.** Click the **+** button, then **Create skill**, then **Upload a skill**.
3. **Upload File.** Upload your SKILL.md file with your instructions. Claude takes it as a ZIP file of your skill's folder, with SKILL.md inside.
4. **Attach.** Link the skill to a project so it loads automatically.

<Callout kind="headsup">
Claude's menus change often, so a button may have moved since this was written. If you can't find one, look for **Skills** under **Customize**.
</Callout>

Your skills are listed on the left. The one open here is called algorithmic-art. Its folder holds SKILL.md and the other files it uses, like templates.

Its SKILL.md starts with the skill's name and a description that tells Claude what the skill does and when to use it. The instructions come after that.

The same menu also has **Create with Claude** and **Write skill instructions**, if you'd rather not upload a file.

<Figure src="/lessons/module-4/directory-skills-tab.png" alt="The Directory window on its Skills tab, with a search box and the Anthropic & Partners filter selected. The **+** menu also has **Browse skills**. It opens a directory of ready-made skills you can add.
