Claude doesn't only work in a chat window. It can also work inside Microsoft Excel, right next to your spreadsheet.

## Advanced Data Operations

Use Claude directly inside Excel to analyse, explain, and act on your spreadsheet data — no switching tabs or copy-pasting.

- **Formula Assistance:** Write, fix, and explain complex <Term term="formula" def="a calculation in a spreadsheet cell, such as adding up a column.">formulas</Term> in plain English
- **Data Analysis:** Summarise trends, flag <Term term="anomaly" def="a number that doesn't fit the pattern of the rest.">anomalies</Term>, and interpret results across large datasets
- **Audit & Validation:** Trace logic errors and verify <Term def="the rules a business's numbers are meant to follow.">business rules</Term> step-by-step

In plain words: Claude can write the maths for you, tell you what the numbers mean, and check for mistakes.

It can also do jobs in the sheet for you: sort and filter, highlight cells with conditional formatting, and make charts. When it answers a question, it gives <Term def="labels that show exactly which cells an answer came from, so you can click them and check.">cell-level citations</Term>. ([Use Claude for Excel](https://claude.com/docs/office-agents/excel))

## Try it: what does the weather data show?

This part needs access; see [how hands-on access works](/access). Open Claude using the access your Code for All session gives you.

### What you need

Claude for Excel is an <Term def="a small extra you add to a program to give it a new ability.">add-in</Term>. It works in ([Use Claude for Excel](https://claude.com/docs/office-agents/excel)):

- **Excel on the web**, which is free with a Microsoft account
- **Excel on Windows** with Microsoft 365
- **Excel on a Mac**, version 16.46 or later

It doesn't work in Excel 2016 or 2019 (the versions you buy once, without Microsoft 365), on an iPad or on Android. If you have one of those, use Excel on the web on a laptop or a Chromebook instead ([which device do you have?](/access#devices)).

Claude for Excel needs a paid Claude plan (Pro, Max, Team or Enterprise); it doesn't work on the free plan. The access your Code for All session gives you covers it, so there's nothing to buy.

### Open Claude in Excel

1. **Add Claude to Excel.** Open the [Claude for Microsoft 365 listing](https://marketplace.microsoft.com/en-us/product/office/WA200010725?tab=Overview) on Microsoft Marketplace (it used to be called AppSource) and select **Get it now**. If it asks you to sign in, use the Microsoft account you use for Excel.

   Or, from inside Excel on the web: **Home**, then **Add-ins**, then **More Add-ins**. Open the **Store** tab, search for Claude, and click **Add**.
2. **Open Excel** and open any workbook. A new blank one is fine for now.
3. **Open the add-in.** In Excel on Windows and on the web: **Home**, then **Add-ins**. On a Mac: **Tools**, then **Add-ins**. Choose Claude.

   You should now see a Claude panel open beside your sheet, like in the screenshots above.
4. **Sign in** with your Claude account, using the access your Code for All session gives you.

   You should now see a box in the panel where you can type a question.

These steps come from the official [Claude for Excel docs](https://claude.com/docs/office-agents/excel). Menus move around, so if a button isn't where this says, look for **Add-ins**.

### Get the data

Download the data: <a href="/lessons/module-4/singapore-weather.csv" download>singapore-weather.csv</a>

It holds 90 days of daily weather for Singapore, from 28 June to 25 September 2026: the highest, lowest and average temperature, the rainfall, the hours of rain, the highest wind speed and the hours of sunshine for each day. A CSV is a simple spreadsheet file that Excel can open.

Weather data: [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0)

5. **Open singapore-weather.csv in Excel.**

   You should now see headings in row 1 and 90 days of data in rows 2 to 91. The columns are:

   | Column | What it shows |
   | --- | --- |
   | A | Date |
   | B | Max temperature (°C): the hottest it got that day |
   | C | Min temperature (°C): the coolest it got, usually at night |
   | D | Mean temperature (°C): the average for the day |
   | E | Rainfall (mm) |
   | F | Hours of rain |
   | G | Max wind speed (km/h) |
   | H | Hours of sunshine |

   If Excel on the web won't let you edit the file, make a new blank workbook and copy the data into it.
6. **Open the Claude panel** again if it closed (**Home** or **Tools**, then **Add-ins**).

<Callout kind="tryit">
Find out what the data shows, and explain it in your own words.
</Callout>

7. **Ask Claude to explain what the data shows.** For example, ask about trends, the hottest and wettest days, and whether rainy days are cooler.

   Here's one way to ask. It's only an example, so change it however you like:

   ```prompt title="Example question"
   Explain what this weather data shows. What are the main trends? Which were the hottest and wettest days? Are rainy days cooler than dry days? Tell me which cells you used for each answer.
   ```

   You should see an answer in the panel, with labels showing which cells each number came from.

### Stay safe

- **Read before you say yes.** When Claude wants to do something risky, it asks you to confirm first, and it warns you before it writes over data that's already there. Read what it's about to change.
- **Only use spreadsheets you trust.** Anthropic's docs warn that files from other people can hide instructions that try to trick Claude. The weather file from this page is safe.
- **Check its answers.** Claude can make mistakes. Click its citations, or find the cells yourself.

### More questions to try, one at a time

Asking one small question at a time makes each answer easier to check. These are examples; try them in order.

**Start with questions that only read the sheet:**

```prompt title="Example 1: understand the columns"
In simple words, what does each column in this sheet show?
```

```prompt title="Example 2: find a fact"
Which date had the most rainfall? Tell me which cell you used.
```

You should see Claude name a date and a cell in column E. Click its citation, or find the cell yourself, and check the number.

```prompt title="Example 3: compare two groups"
Are rainy days cooler? Compare the average Max temperature on days with 5 mm of rain or more and days with less than 1 mm. Explain your formula. Don't change the sheet.
```

```prompt title="Example 4: explain a formula"
Explain this formula in plain English: =AVERAGEIF(E2:E91,">=5",B2:B91)
```

You should see Claude explain that the formula looks down the rainfall column, picks the days with 5 mm or more, and averages their Max temperature.

**Then try questions that change the sheet:**

```prompt title="Example 5: make a chart"
Make a line chart of Max temperature by date on a new sheet.
```

```prompt title="Example 6: highlight cells"
Highlight the five wettest days.
```

Examples 5 and 6 change the file. That's fine: if anything goes wrong, download a fresh copy of the CSV from this page.

### Check it worked

8. **Check its answers against the cells.** If Claude says a day was the wettest, find that date and look at its Rainfall (mm) cell. Then answer each question below from what Claude told you, and reveal the answer to compare. If Claude said something different, find the cell and see who's right.

9. **Explain what the data shows in your own words**, in two or three sentences, not Claude's words. That's the first half of this module's Challenge done.
