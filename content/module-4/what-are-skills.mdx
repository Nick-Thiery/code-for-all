<KeyTerm term="Skill">
A set of instructions you give Claude once, saved as a file. Claude loads it whenever a task needs it, so you don't have to explain the same thing in every chat.
</KeyTerm>

In Module 1 you learned that the more you tell an AI, the less it has to guess. A skill lets you write those instructions once and keep them.

## 1. Reusable Instructions

Teach Claude your workflows, brand guidelines, or domain preferences once. Skills store these as reference files so you never have to repeat yourself across conversations.

Instead of explaining how you like things done at the start of every chat, you write it down once as a skill.

## 2. On-Demand Loading

Skills stay packaged until needed. Claude identifies the relevant skill for your task and loads it automatically, keeping your <Term def="everything Claude is keeping in mind during a conversation. It can only hold so much at once.">context window</Term> lean and efficient.

You don't have to pick the skill yourself, and it doesn't take up space in the conversation until your task needs it.

## 3. Consistent, Standardised Outputs

Define exactly how Claude should deliver results — formatted documents, code modules, structured data — and get the same quality every time without re-prompting.

You describe the result you want once, and you get it the same way every time.
