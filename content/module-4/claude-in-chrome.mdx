## Claude Chrome extension download

This part needs access; see [how hands-on access works](/access).

Download it from the Chrome Web Store: [Claude Chrome Extension Download](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn). The extension is free. Then open it using the access your Code for All session gives you. You don't need to sign up for anything yourself.
