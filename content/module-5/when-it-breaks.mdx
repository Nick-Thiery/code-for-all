Your site will break at some point. That's normal. Here's what to do when it does.

1. **Read the red. Don't panic.** An error is information, not failure. It names the file and the line where things went wrong.
2. **Press F12.** Chrome DevTools opens. Click the Console tab: red text is your actual error. This is the first thing real engineers look at. Now it's the first thing you look at.
3. **Give Claude the whole story.** Paste the exact error, then say what you clicked and what you expected to happen.
4. **Reload and check it yourself.** Refresh the page and test the exact thing that broke. If it's still broken, say so and go around again.

DevTools is a set of tools built into Chrome for looking under the bonnet of a web page. The Console is the tab where errors show up. On a Mac, if F12 does nothing, press Option, Command and I together.

## Practice: the broken sign-up button

In [the last lesson](/module-5/after-hand-off), you asked Claude Code to make the sign-up form really save what people type. Now say you fill in the form, click **Sign up**, and nothing happens. You press F12, click the Console tab and see this in red:

```console title="Console"
Uncaught TypeError: Cannot read properties of null (reading 'value') at script.js:12
```

You don't need to know what it means. Step 3 says what to do with it.
