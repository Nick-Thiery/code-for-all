Claude Design makes your site look right. Claude Code makes it work. The handoff is how your design gets from one to the other.

<HandsOn />

## Hand off your design

- When your design is done, open the **Export** menu.
- Find **"Handoff to Claude Code…"** in the export options. This is the bridge that connects the two tools.
- It gives you a prompt to copy. Open Claude Code in your project folder and paste the prompt in. Claude Code then fetches your design, ready to turn it into a real, working site.

This part needs access; see [how hands-on access works](/access).

<StuckBlock>
  <StuckItem question="I can't find Handoff to Claude Code… in the Export menu.">
    Look in the **Share** menu in the top right. That's where it was when these lessons were first taught.
  </StuckItem>
  <StuckItem question="Claude Code says it can't reach the design.">
    There are two ways to fix it. Connect Claude Code to Claude Design once: run the command Claude Code suggests, then type `/design-login`, then restart Claude Code and paste the prompt again. Or, in the same menu, choose **Project archive** ("Every project file, zipped"; older versions: **Download project as .zip**), put the files in your project folder, and tell Claude Code where they are.
  </StuckItem>
  <StuckItem question="Claude Design asks me to sign up or log in.">
    The hands-on parts need access, which is set up through a Code for All session or a teacher running one. See [how hands-on access works](/access).
  </StuckItem>
</StuckBlock>
