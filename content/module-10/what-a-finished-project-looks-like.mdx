The original course marked the final project against five things. Here they are as questions to ask yourself. There are no points or scores on this site.

<RubricDiagram />

## 1. It ships

Is your project live at a working URL that anyone can open? Does it load properly on a phone and on a laptop? Do all your pages and links work, with none broken? You checked these in [Ship it](/module-10/ship-it).

## 2. It solves something real

Does it solve something real for someone? Can you say who, and how?

## 3. It works end to end

Can someone use it from start to finish without it breaking? Start to finish means every step a real user would take, not just the home page.

## 4. AI-assisted workflow

Can you explain how you used AI to build it? Can you show a prompt that failed and how you fixed it?

A failed prompt isn't a bad sign. Showing how you fixed it is exactly what this asks for.

## 5. Craft and version control

Have you taken care over the details, so it looks and works the way you meant? Is your work in version control, like a GitHub repository, with a history that shows how it grew?
