Your final project starts here. This module is about getting your project a real address, helping people find it, and picking a project worth building.

First, a word you'll meet as soon as you want your own web address.

<KeyTerm term="DNS">
The phonebook of the internet. It turns names like example.com into IP addresses.
</KeyTerm>

An <Term def="the number a computer on the internet is found at. Names are for people; numbers are for computers.">IP address</Term> is a string of numbers. Computers find each other by number. People remember names. DNS is the list that matches one to the other.

<DnsDiagram />

So when you type a web address, your browser asks DNS for the number behind the name, then goes to that number. It happens in a fraction of a second, every time.

In the next lesson you'll see how to get a name of your own.
