In Modules 1 and 2 you built in the browser with Lovable. Now you'll build on your own computer, with an AI agent called Claude Code.

<KeyTerm term="Agent">
An AI that works on its own to get a job done. It reads files, runs commands and decides what to do next, instead of only answering in a chat.
</KeyTerm>

Claude Code comes through your Code for All access, like Claude. You don't pay for it.

## Agentic coding system

Claude Code is an AI agent that writes code. It reads your whole project, runs commands and fixes its own mistakes, instead of just suggesting the next line.

Some coding tools only autocomplete: they guess the next bit of code while you type. Claude Code goes further:

- **It reads your whole project,** not just the file you have open.
- **It runs commands** on your computer, in the <Term def="the text window where you type commands for your computer to run.">terminal</Term>, one after another.
- **It finds and fixes its own mistakes.** When something fails, it works out why and tries again.

## For product designers

You don't have to be an engineer to build with Claude Code.

- You describe the features you want in plain words.
- It turns them into a working prototype, fast. A prototype is a first working version.
- It can build working parts of an app, and put complete interactive projects online.
- You don't have to check every line of code yourself.

It's the same idea as <Term>vibe coding</Term> from [Module 1](/module-1/what-is-vibe-coding): you describe it, the AI builds it. The difference is that Claude Code works with the files on your own computer.

## Integrated environments

Claude Code works in three places:

- **The terminal.** You type what you want, and Claude Code replies and works right there.
- **The VS Code extension.** <Term def="Visual Studio Code: an app for writing and editing code.">VS Code</Term> has an official Claude Code extension. It makes changes across several files at once and keeps track of what changed. The extension comes with its own copy of Claude Code for its chat panel. You only need the terminal version as well if you want to type `claude` in VS Code's built-in terminal.
- **The desktop app.** Claude Code in a normal app window, so you don't need the terminal. It's what you'll install in [lesson 3](/module-3/install-claude-code).

On a Chromebook, or a school device that blocks installs, there's a fourth way: Claude Code on the web, which runs in your browser. See [Which device do you have?](/access#devices)
