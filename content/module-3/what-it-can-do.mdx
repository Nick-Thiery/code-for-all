You ask Claude Code for things in plain words, the same way you <Term term="prompt" def="the message you type to tell an AI what you want.">prompted</Term> Lovable. Here are three kinds of job it can do, with example prompts.

## Routines

A routine is a job that repeats. Claude Code can run jobs in the background, again and again. It can run checks on a schedule, like testing your code every day, or carry out a task with several steps. It does all of this right inside the project on your computer.

```prompt title="Check for errors"
Check this folder for errors every hour.
```

```prompt title="Multi-step process"
Run a multi-step process: clean the files, test the code, then generate a report.
```

**Key idea:** Claude Code can handle repeated background workflows inside your local project environment.

In plain words: it can do repeated jobs for you, inside your project, on your computer.

## Refactoring

<Term def="changing how code is written without changing what it does.">Refactoring</Term> is tidying up code. Claude Code can rename things everywhere they appear, change how your files are laid out, and update the versions of the <Term def="ready-made code that your project uses, written by someone else.">packages</Term> your project uses, all across the project at once. It copes with big, complicated folders and keeps the code written correctly.

```prompt title="Rename a variable"
Rename this variable everywhere it appears.
```

```prompt title="Easier to read"
Make this code easier to read while keeping the same functionality.
```

**Key idea:** Claude Code can help clean up or reorganise existing code without changing what the code actually does.

## Session context

Claude Code remembers what has happened so far in your <Term def="one conversation with Claude Code about your project.">session</Term>. So it can quickly undo recent changes, explain code straight away, and answer questions in plain words about what's been going on.

**Key idea:** Claude Code can keep track of

- What commands were run.
- What errors happened earlier.
- What files were changed.
- What you were trying to fix.

So you don't have to repeat yourself. It already knows what you did five minutes ago.
