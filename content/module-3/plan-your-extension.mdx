You're going to build a <Term def="a small add-on that gives the Chrome browser a new feature.">Chrome extension</Term> with Claude Code. That's this module's Challenge, at the end of this lesson.

Snapiq, from [Module 1](/module-1/what-is-vibe-coding), is one.

## Pick a problem you actually have

Bonus points if it solves a problem you genuinely have. Think about the things that annoy you when you use your browser.

## Ideas to start from

Pick something cool:

- a screenshot tool
- a tab organiser
- a YouTube speed controller
- something that highlights words on any page

Remember the [business lesson](/module-3/quick-business-lesson): an idea that already exists is fine. What matters is how well you build it.

<Callout kind="tryit">
Pick a problem you actually have when you use your browser. Write down, in one sentence, what your extension will do about it. That's what you'll build in the Challenge.
</Callout>

<Challenge title="Build a Chrome extension">
Build a Chrome extension with Claude Code. Pick something cool: a screenshot tool, a tab organiser, a YouTube speed controller, something that highlights words on any page.

It must actually install in your browser and work. Bonus points if it solves a problem you genuinely have.

Building it needs Claude Code; see [how hands-on access works](/access). You'll review your extension at the start of [Module 4](/module-4).
</Challenge>
