## What's in an extension

An extension is a folder of files. Chrome reads them and adds what they describe to your browser.

<ExtensionPartsDiagram />

The only file every extension must have is <Term def="the file that tells Chrome what an extension is called, which version it is, what it's allowed to do and which files to use. Every Chrome extension has one.">manifest.json</Term>, and it must sit in the top level of the folder, not inside another folder. ([Extensions: get started](https://developer.chrome.com/docs/extensions/get-started))

Think of it as the label on a jar. It says what's inside, and Chrome reads it before anything else. If the label is missing or smudged, Chrome won't open the jar.

Everything else depends on what your extension does:

- **A popup** is the small window that opens when you click the extension's icon. It's made of `popup.html`, plus `popup.js` for what the buttons do. (Chrome doesn't let a popup run code written inside its HTML file, so the code has to go in its own file.)
- **An icon** is optional. Without one, Chrome shows a plain icon for you.
- **Something that changes web pages**, like the highlighter in the drawing, is only needed if your extension works on pages. A tab organiser changes your tabs instead, so it doesn't need one.

You don't have to write any of these files. Claude Code writes them; you decide what the extension does and check that it works.

### Permissions

To use some parts of Chrome, an extension has to ask for permission in its manifest. Chrome describes some of these permissions in plain words. For example, a tab organiser needs ([tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs), [tabGroups](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)):

- `"tabs"`, so it can read each tab's address and title. Chrome describes this one as "Read your browsing history".
- `"tabGroups"`, so it can name and colour groups of tabs. Chrome describes it as "View and manage your tab groups".

Only ask for what your extension needs. If Claude Code adds a permission and you don't know why, ask it.

## Build it, step by step

This part needs access; see [how hands-on access works](/access).

These steps build a tab organiser called Tab Tidy, as a worked example. For your own idea, change the first prompt and keep the rest of the steps.

### Plan it with Claude Code

1. **Make a new, empty folder** for the extension, like `tab-tidy`, and open Claude Code in it, as in [lesson 3](/module-3/install-claude-code). In the desktop app, choose **Local** and **Select folder**. In the terminal, `cd` into the folder and run `claude`.
2. **Switch to plan mode.** In the terminal, press **Shift+Tab** until it says `⏸ plan mode on`. In the desktop app, choose **Plan** from the mode selector.
3. **Paste your first prompt** and press **Enter**. This is an example for a tab organiser:

   ```prompt title="Example: Tab Tidy, a tab organiser"
   I want to build a Chrome extension called Tab Tidy. When I click its icon, a small popup opens with one button, "Group my tabs". Clicking it puts the tabs in my current window into tab groups, one group per website (for example, all youtube.com tabs together), named after the website. Use Manifest V3 and the chrome.* namespace. Keep it simple: manifest.json, popup.html, popup.js and popup.css only, with no icons, no libraries and no inline JavaScript. Only ask for the permissions it needs. Explain your plan in plain English before writing any code. When you're done, tell me step by step how to load it with Load unpacked and how to test it.
   ```

   For your own idea, fill in the gaps in this one:

   ```prompt title="Example: your own extension"
   I want to build a Chrome extension called [name]. When I click its icon, [what happens]. Use Manifest V3 and the chrome.* namespace. Keep it simple, with no libraries and no inline JavaScript. Only ask for the permissions it needs. Explain your plan in plain English before writing any code. When you're done, tell me step by step how to load it with Load unpacked and how to test it.
   ```

   Why "the chrome.* namespace"? Some newer guides write `browser.` in the code instead of `chrome.`. Older versions of Chrome don't understand `browser.`, but every version understands `chrome.`. ([The browser namespace](https://developer.chrome.com/docs/extensions/develop/concepts/browser-namespace))
4. **Read the plan.** You should see the files it will make, what each one does, and the permissions it will ask for. If anything is unclear, ask about it. In the terminal, choose **No, keep planning** to tell it what to change.
5. **Approve the plan.** In the terminal, choose **Yes, manually approve edits**. In the desktop app, approve it, then check the mode selector says **Manual**.

### Let it build

6. **Approve each file** as Claude Code makes it: **Yes** in the terminal, **Accept** in the desktop app. For Tab Tidy, expect `manifest.json`, `popup.html`, `popup.js` and `popup.css`, and maybe a `README.md` explaining it.
7. **Check the manifest.** Open `manifest.json` and look for the name, the version, the popup and the permissions. For Tab Tidy it should look roughly like this:

   ```json title="manifest.json"
   {
     "manifest_version": 3,
     "name": "Tab Tidy",
     "version": "1.0",
     "action": { "default_popup": "popup.html" },
     "permissions": ["tabs", "tabGroups"]
   }
   ```

   Yours may be laid out differently or have a description too. That's fine.

### Load it into Chrome

Chrome normally installs extensions from the Chrome Web Store. To try one you've made, you load the folder yourself. These steps are from Google's [Hello World tutorial](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world).

8. **Open the Extensions page.** Open a new tab in Chrome, type `chrome://extensions` in the address bar and press **Enter**. (Or click the puzzle-piece **Extensions** button and choose **Manage Extensions**.)
9. **Turn on Developer mode.** It's a switch on the Extensions page.

   You should now see a row of extra buttons, including **Load unpacked**. No Developer mode switch? Your device is probably managed by a school or work. See the Stuck box.
10. **Click Load unpacked** and choose your `tab-tidy` folder: the folder that has `manifest.json` directly inside it. Choose the folder itself, not a file in it.

    You should now see a card for Tab Tidy on the Extensions page. If you see an error instead, look in the Stuck box.
11. **Pin it.** Click the puzzle-piece **Extensions** button in Chrome's toolbar, find Tab Tidy and choose **Pin**. ([Chrome Web Store help](https://support.google.com/chrome_webstore/answer/2664769))

    You should now see its icon in the toolbar, next to the address bar. With no icon file, Chrome gives it a plain one.

### Test it

12. **Try it the way a real person would.** For Tab Tidy, open four or five tabs from two websites. Click the Tab Tidy icon, then **Group my tabs**.

    You should see coloured tab groups, one for each website, each named after it.

### Change it and reload

13. **Ask for a change.** Go back to Claude Code. For example:

    ```prompt title="Example: a next step"
    Add an Ungroup button to the popup that takes all the tabs in my current window out of their groups.
    ```
14. **Reload the extension.** On `chrome://extensions`, click the refresh icon on your extension's card, next to its on/off switch. Changes to `manifest.json` only work after a reload. Changes to the popup show up when you open the popup again, but reloading never hurts.
15. **Test again**, including the parts that worked before.

### Find and fix errors

16. **Look for errors.** If something goes wrong, an **Errors** button appears on the extension's card on `chrome://extensions`. Click it to read the message. ([Debug extensions](https://developer.chrome.com/docs/extensions/get-started/tutorial/debug))

    For problems in the popup, open the popup, right-click inside it and choose **Inspect**, then click the **Console** tab. Errors show in red.
17. **Paste the error into Claude Code:**

    ```prompt title="Example: fixing an error"
    My extension shows this error: [paste the whole error]. Fix it, then tell me how to check it worked.
    ```
18. **Clear the old errors.** Click **Clear all** in the errors list, reload the extension and test again.

**Check it worked:** your extension loads on `chrome://extensions` with no errors, its icon is pinned in the toolbar, it does its job when you try it, and it still works after you reload it. That's the Challenge done.
