Download Claude Code onto your computer. You'll use it to build a Chrome extension for this module's Challenge.

There are two ways to get it. Start with the desktop app. The terminal is the other option, if you'd rather work there.

These steps come from the official [Claude Code docs](https://code.claude.com/docs/en/desktop-quickstart), which is where the class slide sends you.

<HandsOn />

## Option 1: the desktop app

This part needs access; see [how hands-on access works](/access).

1. Open the official [desktop app instructions](https://code.claude.com/docs/en/desktop-quickstart) and download the installer for your computer: macOS or Windows. On Linux, follow the Linux steps linked from that page.
2. Run the installer.
3. Open Claude: from your Applications folder on a Mac, the Start menu on Windows, or your app launcher on Linux.
4. Sign in using the access your Code for All session gives you.
5. Click the **Code** tab at the top centre.
6. Select **Local**, so Claude works on the files on your computer.
7. Click **Select folder** and choose your project folder. A new, empty folder for your Chrome extension is fine.

<Screenshot caption="The Code tab in the Claude desktop app, with Local selected and a project folder chosen.">Claude desktop app, Code tab</Screenshot>

The desktop app includes Claude Code, so you don't need to install anything else to use the Code tab. When the Code tab is open on your folder, you're ready.

<HandsOn />

## Option 2: the terminal

This part needs access; see [how hands-on access works](/access).

1. Open a terminal. Never used one? The official [terminal guide](https://code.claude.com/docs/en/terminal-guide) shows how to open one and paste a command.
2. Run the install command for your computer.

   **macOS, Linux or WSL:**

   <CommandBlock>{"curl -fsSL https://claude.ai/install.sh | bash"}</CommandBlock>

   **Windows PowerShell:**

   <CommandBlock>{"irm https://claude.ai/install.ps1 | iex"}</CommandBlock>

   **Windows CMD:**

   <CommandBlock>{"curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd"}</CommandBlock>

3. When it finishes, open a new terminal window and check that it worked:

   <CommandBlock>claude --version</CommandBlock>

   A working installation prints a version number.
4. To start Claude Code, open a terminal in your project folder and run:

   <CommandBlock>claude</CommandBlock>

   The first time, it opens your browser so you can log in. Log in using the access your Code for All session gives you.

  <StuckItem question="My terminal says claude isn't found or isn't recognised.">
    Open a new terminal window and run `claude --version` again. If it's still not found, the install folder isn't on your PATH yet. The official page [Fix your PATH](https://code.claude.com/docs/en/troubleshoot-install#command-not-found-claude-after-installation) shows how to fix it.

  <StuckItem question="The Windows install command gives an error straight away.">
    You may be in the wrong kind of terminal. If you see `The token '&&' is not a valid statement separator`, you're in PowerShell, not CMD: use the PowerShell command. If you see `'irm' is not recognized as an internal or external command`, you're in CMD, not PowerShell: use the CMD command. In PowerShell, the line you type on starts with `PS`.
  </StuckItem>
