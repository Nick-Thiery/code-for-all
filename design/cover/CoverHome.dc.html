How it works

1

Read a short lesson

Each one takes 3 to 15 minutes, in plain English.

2

Practise with tips

Write a prompt and get kind, specific tips. Sample tips for now, while AI feedback is set up.

3

Build something real

Use an AI agent to build your own website, step by step. Every module ends with a Challenge.
